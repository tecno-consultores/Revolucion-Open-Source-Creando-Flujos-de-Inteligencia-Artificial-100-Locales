# Revolucion Open Source 
## Creando Flujos de Inteligencia Artificial 100% Locales

En un ecosistema tecnológico dominado por servicios en la nube de pago, esta ponencia demuestra cómo recuperar el control total sobre la Inteligencia Artificial. Exploraremos la arquitectura y el despliegue de un stack 100% local y de código abierto, integrando Ollama, Open WebUI, n8n y Evolution API. Demostraremos cómo es posible orquestar modelos de lenguaje avanzados utilizando contenedores y hardware de consumo para automatizar flujos de trabajo complejos y mensajería en tiempo real. El objetivo es brindar a los asistentes las herramientas para construir soluciones de IA soberanas, garantizando la privacidad de los datos y eliminando los costos de inferencia por API.
